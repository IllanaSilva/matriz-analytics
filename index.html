💾 Armazenamento

          
Motor ativo: —

          

            Todos os dados ficam salvos apenas neste navegador (IndexedDB, com fallback
            para localStorage). Nada é enviado a servidores externos. Isso significa que
            limpar os dados do navegador, ou acessar de outro computador, não traz o
            histórico — use a exportação regularmente como backup.
